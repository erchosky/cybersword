## Initial findings and disposition

### Critical

No embedded real credential, private key, production database or confirmed
critical remote vulnerability was found.

### High

1. HTML exports inserted analyzed content directly into markup. A crafted SMS,
   URL, filename or imported result could execute script when a saved report was
   opened. Both generic and session reports now escape keys, values, titles,
   targets and JSON details; generated links accept only HTTP(S) schemes.
2. HTTP helpers and scanning paths silently retried or explicitly requested
   HTTPS with certificate verification disabled. The fallback was removed,
   direct `verify=False` calls were eliminated and secure verification is the
   documented default.
3. AES passwords were converted directly to keys with one SHA-256 operation;
   CBC output was unauthenticated. New version-2 envelopes use PBKDF2-HMAC-SHA256
   with a random salt and 600,000 iterations. GCM is authenticated natively;
   CBC adds encrypt-then-MAC. Legacy v1 GCM decryption remains supported.

### Medium

1. `--quiet --sms` printed Rich UI before JSON and then crashed because `Panel`
   was undefined. The import and output isolation were fixed; the command now
   emits parseable JSON only.
2. Web directory fuzzing referenced `hashlib` before its local import, causing
   the baseline request path to fail. Import ordering and baseline hashing were
   fixed, and SHA-256 replaced MD5 for content comparison.
3. A clean install failed while building the declared `ssdeep` package. Many
   other declared packages were unused, while required `numpy` was missing.
   Direct dependencies were reconciled, exact versions added, and a hash-pinned
   `pylock.toml` was generated for the validated platform.
4. The `python-magic` module name was shadowed by a loop variable, so enhanced
   MIME fallback could never succeed. The collision was fixed. Because macOS
   also requires native `libmagic`, it is now an explicitly documented optional
   dependency instead of a misleading base requirement.
5. Concurrent web workers shared one Requests session. Workers now receive a
   thread-local session, avoiding mutable-session races.
6. Local report/log directories were relative to the caller's working
   directory. They are now anchored to the project root.

### Low

- EXIF fallback wrote to an uninitialized `exif_raw` mapping; initialized.
- Cookie flags were read from string values instead of cookie objects; fixed.
- The setup wizard echoed keys and could create a broadly readable file; input
  is hidden and `config.yaml` is written with mode `0600`.
- Configured API keys can now be supplied through environment variables, which
  override the local YAML file.
- Persistent investigation logging now defaults to off.
- Duplicate, unused imports and cosmetic lint defects were removed safely.
- Runtime requirement and `.python-version` now agree on Python 3.12.

### False positives or accepted findings

- Bandit classifies the `Crypto.*` namespace as obsolete PyCrypto. The installed
  and declared package is maintained PyCryptodome; imports are annotated with
  that justification.
- MD5/SHA-1 remain intentionally exposed as forensic identifiers and for the
  Gravatar/HIBP protocols. Those calls are marked `usedforsecurity=False`; they
  are not used for password storage or cryptographic integrity.
- Broad exception handling remains in optional network/enrichment probes where
  one unavailable source must not abort the overall analysis. It is a
  maintainability limitation, not a claim that every remote check succeeded.

## Debugging and repairs

### SMS CLI and quiet mode

- Symptom: `python cybersword.py -q --sms ...` produced terminal decorations and
  `{"error": "name 'Panel' is not defined"}`; JSON parsing failed.
- Cause: missing import plus feature functions writing directly to stdout.
- Files: `cybersword.py`, `modules/sms_analyzer.py`.
- Repair: import `Panel` and capture feature output only in quiet CLI mode.
- Validation: subprocess regression parses the complete stdout with `json.loads`.

### Web fuzzing

- Symptom: baseline calculation referenced an unbound `hashlib`, masking the
  intended custom-404 comparison.
- Cause: function-local import after first use.
- Files: `modules/web_scanner.py`.
- Repair: module import, SHA-256 baseline, per-thread sessions and verified TLS.
- Validation: mocked custom-wordlist regression executes the complete function.

### HTML report injection

- Symptom: report data such as `<script>` and attacker-controlled attributes
  were emitted as active markup.
- Cause: f-string rendering without context-appropriate escaping.
- Files: `utils/output.py`, `modules/reporter.py`.
- Repair: HTML escaping, safe link schemes, `noopener noreferrer`, unique row IDs.
- Validation: two tests assert payloads cannot appear as executable markup.

### Cryptography

- Symptom: identical password-derived AES keys across messages and no CBC
  integrity check.
- Cause: unsalted single SHA-256 derivation and raw CBC envelope.
- Files: `modules/crypto.py`.
- Repair: versioned salted PBKDF2 envelopes and authentication, with legacy GCM
  compatibility.
- Validation: GCM/CBC round trips, wrong-password rejection and legacy decrypt test.

### Dependency restoration

- Symptom: `pip install -r requirements.txt` failed while building `ssdeep`.
- Cause: an unused native extension was mandatory; the manifest also omitted
  `numpy` and listed numerous unused libraries.
- Files: dependency manifests and README.
- Repair: reconcile direct dependencies, separate optional `libmagic`, add dev
  requirements and a platform-specific hash lock.
- Validation: clean-copy restoration is recorded in the validation table below.
